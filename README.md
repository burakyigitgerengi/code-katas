# Code Katas

A collection of programming exercises, coding katas, experiments, and small projects created for learning, practice, and continuous improvement.

> ⚠️ **Educational Project**
>
> This repository is created for educational and personal learning purposes. The code may contain experimental, incomplete, or simplified implementations and should not be considered production-ready software.
>
> **Do not use code from this repository in production without reviewing, testing, and adapting it to your own requirements.**

## 🇬🇧 English

This repository is a personal collection of programming challenges and projects built while learning and improving software development skills.

It may contain exercises and projects related to:

* Data Structures & Algorithms
* Problem Solving
* Python
* Java
* Object-Oriented Programming
* Software Development
* Small Applications & Experiments
* Programming Concepts and Techniques

The contents of the repository will continue to grow and change over time as new topics are learned and new projects are created.

### Purpose

The goal is not simply to collect solutions, but to **practice writing code, understand problems, make mistakes, experiment with different approaches, and improve over time**.

Some solutions may be simple or imperfect. That's intentional — this repository represents the learning process rather than a collection of polished production projects.

### Technologies

The technologies used in this repository may vary between projects. Current and future exercises may use different programming languages, libraries, frameworks, and tools depending on what is being studied.

### Disclaimer

This repository is provided for educational purposes.

Some code may be experimental, incomplete, inefficient, or written specifically to demonstrate a particular programming concept. Always review and test code before using it in any real-world application.
